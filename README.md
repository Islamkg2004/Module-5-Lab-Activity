This repository contains my Python programming assignments from National Louis University.

Module 5: Lab Activity – Iterative Programming

This module contains five Python programming exercises focused on loops, iteration, and the Turtle graphics library.

Problem 1 – Hello World

A program that uses a loop to print "Hello World" 100 times. A flowchart is also included to show the program's execution.

Problem 2 – Numbers and Squares

A program that uses loops to print a list of numbers and calculate the square of each number.

Problem 3 – Regular Polygon

A program that asks the user for the number of sides, side length, line color, and fill color. It uses Python Turtle to draw and fill a regular polygon.

Problem 4 – Divisibility

A program that iterates through numbers from 1 to 50. It identifies numbers divisible by three, five, or both. A flowchart is also included.

Problem 5 – Turtle Drawing

A creative drawing program using Python Turtle methods to create a picture.
